# 四级备考 · 个人学习网页

面向 **2026 年 12 月大学英语四级**的个人备考网页。响应式设计,电脑与手机共用同一套页面;无账号、无社交、无积分;学习数据保存在当前浏览器。

## 快速开始

### 方式一:双击启动(推荐)

双击 **`启动网页.bat`**,会自动启动本地服务器并打开浏览器(地址 `http://127.0.0.1:8000/`)。

### 方式二:直接打开

双击 `index.html` 也可以使用(词库已内嵌为 JS 数据文件);但此方式下 PWA/离线缓存不可用。

### 手机访问

将整个文件夹放到局域网内可访问的服务器,或用任意静态托管(如 GitHub Pages)发布后,手机浏览器打开同一地址即可。添加到主屏幕后体验接近原生 App。

## 已实现功能

### 首页
- 四级考试倒计时(考试日期手动设置,不写死)
- 今日新词进度(默认 30,可修改)
- 今日有效学习时长(切后台 / 2 分钟无操作自动暂停)
- 四个学习入口 + 每周复习提醒(默认周日,可修改)

### 单词与短语
- 词库:**2607 个 CET4 词条**,来源 qwerty-learner 开源词库,含中英文释义、美/英音标
- 练习:看英文选中文、看中文拼写英文、英文短语译中文、中文短语译英文
- 顺序 / 随机学习;练习范围可选**全部 / 仅未掌握 / 仅错词**;每轮题量 20/50/100/全部
- Web Speech API 英美发音,可重听
- **掌握标准**:同一词条在三次独立练习中连续答对;答错归零;查看答案后作答不计入;已掌握答错则回到待巩固
- 短语为自编常用搭配(**141 条**),允许合理同义表达判对
- **例句**:作答后自动显示;词库本身不含例句时不编造,可点击「AI 生成例句」按需生成(标注 **AI 生成**,本地缓存,需配置 AI 服务)

### 听力
- 单词听写、短语听写、短句理解(**25 条**)、短对话理解(**6 段**)、场景短文挖空(**8 篇**)
- 慢速播放、重复播放、随时查看原文
- 查看原文后作答记为**辅助完成**,得分折半,与独立作答分开统计
- 所有语音为**浏览器合成语音**,界面明确标注;本版不包含四级真题音频(真题需使用可合法获得的材料另行导入)

### 作文
- **28 个练习话题**(覆盖校园、社会、科技、成长四类),另支持**自定义题目**
- 四级作文模板与常用句型
- 在线 AI 批改:15 分制参考评分、等级、总体评价、逐处问题定位与修改建议
- 未配置 AI 服务或请求失败时**不显示任何评分**
- 作文原文、批改时间、评分、批改结果本地保存,支持查看与删除
- 提交前提示第三方服务处理;评分明确标注为 AI 参考

### 数据与外观
- 全部数据保存在浏览器 localStorage;**手机与电脑各自保存,不自动同步**
- 支持导出 / 导入 JSON、清空全部数据
- 主题:浅色 / 护眼 / 纯色 / 自定义图片背景(**遮罩透明度 0~90% 可调**)
- 统计:连续学习天数、今日时长、已掌握/未掌握、单词正确率、易错词 Top10

## AI 批改配置

设置 → AI 作文批改服务,填写:
- 接口地址(OpenAI 兼容,如 `https://api.example.com/v1`)
- API Key
- 模型名称

要求接口支持 `/chat/completions` 且允许浏览器跨域(CORS)调用。Key 仅保存在本浏览器,请勿在公用电脑上配置。

## 已知边界

- 词库不含例句、词根词缀、搭配、近反义词,相关模块按需隐藏(未强行补充)
- 本版听力只含自编材料与合成语音,不含真题音频
- AI 评分依赖第三方服务,网络/接口异常时不会生成评分
- 本地数据不跨设备同步,请用导出/导入手动迁移
